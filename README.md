# Large Language Model Virtual Studio (llmvs)

Condense the inheritance trees of your massive C++ codebase into an LLM friendly
command line chat interface.

For those not interested in LLM gimmicks you can use it as command line inheritance tree explorer.

## Deps

* nlohmann-json
* GNU readline
* LLVM libtooling
* cURL
* A local ollama server running your favorite model.
